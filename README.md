# VIPList clickable prototype

A clickable prototype of VIPList: guests find tonight's events and claim
free guest-list spots, door staff check passes, and promoters post events
and manage their claims.

**Try it:** https://vishalkanwar-synaptiq.github.io/viplist-prototype/

It runs entirely in the browser with made-up data; nothing is sent
anywhere. Built from the design in the private `viplist` repository.
